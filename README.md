# 信息茧房

**把想看的留下，其他资讯交给进度条。** 这是一款给橘鸦Juya的 B站 AI 早报用的 Edge 扩展。名字叫“茧房”，但门把手在你手里：一个总开关，想拆就拆。

它只在 **UP 主姓名与 UID 都确认为橘鸦Juya** 的视频页工作，不会接管你刷到的其他视频。

## 它会做什么

- 先读置顶评论的时间轴；如果索引写在置顶下的作者回复里，也会接上。置顶正文和回复各写一半时，会合并成一份。
- 评论里没有索引时，尝试从视频底部的章节条切片并 OCR。看不清的片段会**保留**，避免把感兴趣的内容一脚踢过去。
- 按关键词决定保留或跳过，真正控制播放器跳到下一段。默认词是 `OpenAI`、`GPT`、`Codex`、`Claude`、`Anthropic`、`DeepSeek`；你可以新建、命名和编辑自己的关键词集合。
- 总开关会记住状态。刷新页面、打开下一期或在 B站站内切换视频，都不用再按一次。弹窗会显示时间轴来源、资讯数、保留数、跳转次数和日志。

另外还有一个**手动 OCR 检查**按钮，只输出识别日志；它不替换正在使用的跳段结果。首次 OCR 需要联网加载 Tesseract.js 和英文识别模型。

## 安装与使用

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择整个 **`C:\Lab0916\Juya`** 文件夹（里面能看到 `manifest.json`）。不需要 Node.js，也不用构建。
3. 打开橘鸦Juya的一期 B站 AI 早报，先播放几秒，让播放器加载完成。
4. 点击工具栏上的橘鸦头像，选好关键词集合，打开**总开关**。接下来让茧房替你快进；要看完整视频，关掉总开关即可。

更新本地文件后，到 `edge://extensions` 点击本扩展的“重新加载”，再刷新已经打开的视频页。关键词和总开关设置会保留。若弹窗长时间显示“检查中”，可等评论区加载后再刷新页面；失败原因会写在弹窗日志中。

## 现在的边界

评论时间轴是首选。OCR 降级会反复核对章节边界；边界不一致、识别失败或一个关注词都没找到时，它宁愿不跳。OCR 的单字符错字可做有限的模糊匹配，例如 `OpenAl` → `OpenAI`，但它不是语义模型，也不会保证每期视频都能识别。

代码与模拟播放器测试：在本目录运行 `node --test tests/*.test.cjs`。现有 Edge 实测记录位于 `tests/`；**0.4.0 的自动 OCR 降级还没有在真实无评论索引的视频上完成复测**。开发检查点 `v0.4.0-ocr-fallback` 保存了本次改名之前的完整版本，0.3.1 则在 `v0.3.1-working-extension`。
