# 信息茧房

**想看的留下，不想看的让进度条先走一步。** 信息茧房是一款给橘鸦Juya的 B站 AI 早报用的 Edge 扩展。名字听着像把自己关起来，但门把手一直在你手里：总开关一关，视频照常完整播放。

目前只支持**UP 主姓名与 UID 都匹配橘鸦Juya**的视频。它不是全站通用的 AI 摘要器，也没有 LLM。

## 能做什么

- **读时间轴：**优先取置顶评论；作者把索引写在置顶下的回复里，或者正文与回复各写一半，也能读取并合并。
- **没有评论索引时尝试 OCR：**从视频底部章节条切片、识别标题，再按当前关键词集合判断。边界或文字不可靠时会保留片段，必要时整页停止跳段。
- **自动跳段：**默认关注 `OpenAI`、`GPT`、`Codex`、`Claude`、`Anthropic`、`DeepSeek`。可新建、命名、编辑关键词集合；弹窗显示来源、保留数、跳转次数与日志。
- **一个总开关管后续视频：**刷新、打开新视频或站内切换时自动检查，关闭则停止跳段。旁边的“手动 OCR 检查”只输出日志，不替换当前跳段结果。

## 安装

先克隆这个仓库；有仓库访问权限也可以在 GitHub 的 **Code → Download ZIP** 下载并解压。

```powershell
git clone https://github.com/fumingyang2004/information-cocoon.git
```

1. 在 Edge 地址栏打开 `edge://extensions`，开启**开发人员模式**。
2. 点击**加载解压缩的扩展**，选择刚克隆或解压的仓库文件夹。选包含 `manifest.json` 的那一层；不要选 `imgs`，橘鸦虽然可爱但不能单独当扩展运行。
3. 打开橘鸦Juya的一期 B站 AI 早报，先播放几秒让播放器加载。点击工具栏上的橘鸦头像，选择关键词集合，打开**总开关**。

本地安装不需要 Node.js 或构建步骤。更新代码后，在 `edge://extensions` **重新加载扩展**，再刷新已打开的视频页；已保存的总开关与关键词集合会保留。

## 看不到跳段？

弹窗日志会显示时间轴来源、解析结果和实际 `SEEK` 行为。评论可能懒加载；若一直显示“检查中”，等评论区加载后刷新页面。没有可用索引、OCR 边界不一致、识别失败或一个关注词都没找到时，扩展不会盲跳。OCR 会短暂移动播放位置取帧，然后恢复。

OCR 英文标题支持大小写不敏感、相邻词拼接，以及长度至少五字符的单字符模糊匹配，例如 `OpenAl` → `OpenAI`。空白、低置信度或文字太短的片段会保留；这会少跳一些，但能减少错字造成的误跳。首次 OCR 需要联网加载 Tesseract.js 和英文模型。

## 开发与验证

扩展是 Manifest V3，代码直接位于仓库根目录。`background.js` 与 `autostart.js` 管总开关和页面切换；`juya-demo.js` 读取时间轴并控制播放器；`page-bridge.js` 将状态和日志送到弹窗。

```powershell
node --test tests/*.test.cjs
```

现有测试覆盖评论主路径、作者回复、OCR 错字与保守跳段、关键词集合和模拟播放器 seek。`tests/` 也保存了此前 Edge 的实验记录。**自动 OCR 降级仍需在真实“无评论索引”视频上复测**；这项测试不能靠模拟播放器冒充。

扩展权限限于脚本注入、本地设置、标签页/站内导航检测以及 `www.bilibili.com`。没有账号后台服务；设置保存在扩展本地存储，页面日志留在当前页面。OCR 所需脚本和模型会从 CDN 下载。

改名前的代码保存在 Git 标签 `v0.4.0-ocr-fallback`；更早的可运行版本是 `v0.3.1-working-extension`。
